# AI 품질 대비 비용 최적화 실험

## 1. 목적

AI 요약과 분석은 품질이 중요하지만, 입력 길이와 출력 길이에 따라 토큰 사용량과 비용이 크게 증가할 수 있습니다. 본 문서는 비용을 줄이면서도 품질을 유지할 수 있는 실험 방법을 정리한다.

## 2. 기본 측정 항목

### 2.1 입력/출력 토큰 사용량

- 입력 토큰: 기사 제목 + 본문 + 시스템 메시지 + 사용자 메시지
- 출력 토큰: 요약, 분석 결과, 비교 결과의 길이
- 모델 호출 시 전체 토큰량을 함께 측정

### 2.2 예상 비용

비용은 보통 아래 요소에 비례한다.

- 입력 토큰 수
- 출력 토큰 수
- 모델 종류
- 호출 횟수

이 프로젝트는 요약과 분석을 반복 호출하므로, 긴 본문을 그대로 넘기면 비용이 급격히 커질 수 있다.

## 3. 실험 구성

### 3.1 실험 그룹

1. Full-text 요약: 기사 전체 본문을 그대로 전달
2. Truncated 요약: 본문 일부만 전달
3. Structured summary: 핵심 문장만 추출 후 전달
4. Topic-only summary: 제목 + 키워드 중심 입력

### 3.2 비교 기준

- 요약 품질
- 분석 정확성
- 핵심 정보 포함률
- 입력 길이에 따른 응답 안정성
- 응답 속도
- 전체 비용

## 4. 세부 평가 방식

### 4.1 요약 품질 평가

- 핵심 사실이 누락되지 않았는지 확인
- 기사 본문에 없는 추정 정보가 포함되지는 않았는지 확인
- 출력 길이가 3문장 기준 이하인지 확인

### 4.2 분석 품질 평가

- trend, keywords, issues, implications가 일관되게 구성되는지 확인
- 소스별 비교에서 실제 차이가 반영되는지 확인
- JSON 파싱 가능 여부와 필드 누락 여부 확인

## 5. 비교 방법

- 동일 기사 세트에 여러 입력 길이 조건을 적용
- 결과를 수동 평가 점수와 JSON 파싱 성공률로 비교
- 비용 계산: 토큰 수 × 단가를 추정
- 그래프로 시각화하여 "품질-비용 트레이드오프
